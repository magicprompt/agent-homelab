Setup guide.

Exact links, exact commands, in order. Required steps first, optional upgrades after. Once your agent and network are up, hand the rest to your agent — a sample prompt is included for each step.

Required

01An always-on machinehardware

Any computer you can leave powered on 24/7: a spare Mac mini, an old laptop, a NUC, a cheap home server. No purchase needed if you already own one.

02Install an agent — Hermes Agentsoftware

Open-source, self-hosted agent framework. Any model provider, same session across every surface.

GitHub repo Docs 
curl -fsSL https://hermes-agent.nousresearch.com/install.sh | bash
hermes setup
hermes
03Join a private network — Tailscalenetwork

Mesh VPN. Every device gets a stable private address reachable from anywhere — nothing opened to the public internet.

Download Install docs Explainer video ↗ (3rd-party)

Prompt for your agent

"Install Tailscale on this machine, walk me through logging in, confirm it's connected to my tailnet, and show me this machine's Tailscale IP and hostname."

Recommended

04Reach it from your phoneaccess

Wire a messaging bot (e.g. Telegram) into your agent so you can message it from anywhere. Configured inside Hermes itself — see the messaging section of the docs.

Hermes messaging docs

Prompt for your agent

"Set up a Telegram bot for yourself using BotFather, wire it into your messaging config, and confirm I can message you from my phone."

05Keep terminal sessions alive — herdrtooling

Agent-aware terminal multiplexer. Coding-agent sessions (Claude Code, Codex, etc.) keep running after you disconnect; reattach from anywhere, including over SSH.

Site Install docs 
brew install herdr
# or
curl -fsSL https://herdr.dev/install | sh

For iOS/Android, pair it with Moshi — an SSH/Mosh terminal client built for agent sessions (tmux/herdr aware, Live Activities, Apple Watch approvals).

Site App Store
06Full remote screen — Jump Desktopaccess

Remote desktop app for when a task needs a GUI, not just a terminal. Auto-detects your Tailscale connection — no port forwarding needed.

Site Pricing

Free for Windows clients; Mac/iOS/Android plans from roughly $7.49/user/month. A free tier covers light personal use.

Optional upgrades

07Local models — Ollamaprivacy

Run open models on your own hardware. No API key, nothing leaves your network. Good fallback when cloud providers are down.

Download
curl -fsSL https://ollama.com/install.sh | sh
ollama pull llama3.1
ollama run llama3.1

Prompt for your agent

"Install Ollama on this machine, pull a solid general-purpose model (llama3.1 or qwen2.5 are good defaults), start the Ollama server, and give me the local endpoint so I can point a tool at it. Also set it up to run on this machine's Tailscale address so I can reach it from my other devices."

08Own your memory — Hindsightprivacy

Self-hosted long-term memory for your agent. Runs fully locally against Ollama — no cloud, no API keys, the record of your conversations stays on your hardware.

GitHub repo Run it with Ollama ↗
09Ride out power blips — UPSresilience

A small battery backup keeps the machine up through brief outages so a task doesn't die mid-run. Any UPS rated for your machine's wattage works.

CyberPower battery backups ↗
10Recover from a hard lockout — KVM-over-IPresilience

If the machine crashes, hangs on boot, or SSH becomes unreachable, a hardware KVM gives you a physical keyboard/video/power connection over the network — the deepest recovery tier.

GL.iNet Comet Pro (GL-RM10) ↗ — ~$99

General pattern once steps 2–3 are done: describe what you want to the agent running on the machine and let it install and configure the rest. It has a shell — that's the point.
